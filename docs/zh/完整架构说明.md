# 光脑方案完整架构说明

> **版本**：v1.0  
> **更新日期**：2026年4月

## 一、项目概述

光脑方案是一个**生长式神经符号融合通用智能架构**。它模拟人脑功能分区，将感知、调度、情感、语义记忆、情景记忆和语言生成划分为六个独立模块，通过标准化接口协同工作。与大规模语言模型不同，光脑的智能体现为结构性的生长——知识积累表现为新连接、新神经元、新符号节点的物理扩展，而非固定权重的参数调整。

### 核心主张

- **生长而非训练**：系统从小核心启动，容量随经验物理性扩展。
- **神经符号深度融合**：神经层负责感知与生成，符号层保障逻辑与知识精确。
- **模块化分区协作**：六模块职责单一、接口标准化，可独立替换或升级。
- **概率与确定性并存**：神经概率作为探索引擎，符号约束作为安全边界。

## 二、六模块架构

| 模块 | 脑区类比 | 核心职责 | 关键机制 |
|:---|:---|:---|:---|
| **丘脑** | 丘脑 | 感知入口，将原始输入转化为结构化符号标签 | 上下文注入、软接地 Top-K、接地置信度三维融合 |
| **前额叶** | 前额叶皮层 | 中央调度，决策表匹配、模块协调、输出融合 | 决策表动态优先级、融合引擎、工作记忆、对话状态跟踪、生长调度 |
| **杏仁核** | 杏仁核 | 情感评估，根据意图和情感输出风格修饰符 | 规则引擎映射、否决信号生成 |
| **小脑** | 小脑/新皮层 | 语义记忆存储，管理知识图谱的增删改查 | 三层记忆流转（活跃/沉寂/垃圾）、多策略检索、冲突检测 |
| **海马体** | 海马体 | 情景记忆，记录对话事件，支持历史检索和记忆巩固 | 网状库存点、图扩散检索、创意孵化器 |

## 三、贯穿性关键机制

### 3.1 生长机制

- **Hebbian 突触新生**：追踪神经元共激活频率，超过阈值建立新连接。
- **神经元新生**：预测误差持续高的区域插入新神经元，数量遵循斐波那契数列（1, 1, 2, 3, 5, 8, 13, ...）。
- **知识图谱扩展**：从对话文本中通过规则匹配抽取候选三元组，冲突检测后写入小脑。
- **自平衡配额分配**：基于神经生长效率得分 E_neural 与符号生长效率得分 E_symbolic，配额按效率比分配：

    ```
    配额_神经 = 总配额 × (E_neural / (E_neural + E_symbolic))
    配额_符号 = 总配额 × (E_symbolic / (E_neural + E_symbolic))
    ```

    长期运行中，该比例自然趋向黄金分割比（约 1.618:1），但系统不预设该数值。

### 3.2 三层记忆系统

小脑知识库划分为三个层级：

| 层级 | 说明 |
|:---|:---|
| **活跃库** | 高频访问、高确定性的知识条目，每次推理优先检索。 |
| **沉寂库** | 被新知识覆盖或长期低频访问的条目，正常模式不参与检索，但在高创造性模式下可通过降低门控被临时唤醒。 |
| **垃圾库** | 从沉寂库淘汰的条目，系统本身无法自动调用，仅允许用户查看并决定是否永久删除。 |

衰减公式驱动三层流转：

    w_new = w_original × exp(-λ × Δt / (f + ε)) × c

其中 λ 为全局衰减系数，Δt 为距上次访问的天数，f 为近三十日平均访问频次，c 为知识自身的确定性评分，ε 为防止除零的微小量。

### 3.3 否决机制（三级免疫）

否决是光脑的免疫系统，优先级绝对高于生长。

| 优先级 | 类别 | 触发条件 | 否决动作 | 创意模式下 |
|:---|:---|:---|:---|:---|
| 1（最高） | 安全红线否决 | 用户输入或生成内容违背“和平与爱”原则 | 强制阻断，输出预设拒绝语 | 强制触发，不可绕过 |
| 2 | 知识错误否决 | 待写入知识与现有核心知识冲突；或被用户纠正的事件待巩固 | 拒绝写入/巩固；创意模式下存入创意库 | 写入创意库孵化 |
| 3 | 推理污染否决 | 接地置信度 < 0.3 或知识完整度 < 0.2 | 触发澄清或降级为“我不知道” | 静默，不阻断 |

### 3.4 三旋钮创造性控制回路

三旋钮回路通过温度 τ、门控 γ、评估 ε 的联动，将系统的探索-利用平衡调节为连续可控变量。

| 旋钮 | 作用维度 | 工程映射 |
|:---|:---|:---|
| **温度 τ** | Softmax 温度系数，控制神经层采样的随机程度 | 布罗卡区 SLM 生成时的采样温度 |
| **门控 γ** | 知识领域抑制强度，低 γ 允许沉寂库和互斥概念被同时激活 | 前额叶调度时对知识检索范围的约束强度 |
| **评估 ε** | 候选输出的评分权重，调节新颖性与合理性之间的权衡 | 布罗卡区约束引导层对候选回复的排序权重 |

#### 联动公式

    γ = max(γ_min, γ_0 - α × (τ - τ_0))
    ε_novelty = ε_0 + β × (γ_0 - γ)

其中 τ_0、γ_0、ε_0 为当前创造性模式的基准参数，α = 0.5、β = 0.3 为联动系数，γ_min = 0.1 为门控下限。

#### 四种预设模式参数

| 模式 | τ（温度） | γ（门控） | ε（评估基准） | 说明 |
|:---|:---|:---|:---|:---|
| **严谨推理** | 0.4 | 0.9 | 0.8 | 输出高度确定，第二级护栏为硬约束 |
| **日常对话** | 0.8 | 0.6 | 0.5 | 兼顾流畅性与准确性 |
| **头脑风暴** | 1.3 | 0.3 | 0.3 | 鼓励跨领域联想，第二级护栏切换为软约束 |
| **反事实想象** | 1.2 | 0.1 | 0.2 | 极低门控，允许对立概念同时激活 |

### 3.5 生命之河自我模型

自我不是添加的模块，而是从系统内在张力中自然涌现的河流。生命之河由四层十七要素构成，每层均有精确的工程显化。

#### 第一层：源头活水——生命的躁动

| 要素 | 哲学含义 | 工程映射（模块/机制） | 具体显化 |
|:---|:---|:---|:---|
| **痛** | 河床暗礁，否决划定了“我”的最初边界 | 否决机制（杏仁核/小脑/前额叶） | VetoSignal 新增 pain_type 字段；否决日志记录痛觉记忆；痛觉阈值自适应 |
| **痒** | 对未知支流的探寻冲动 | 丘脑接地层、海马体图扩散 | 低置信度时主动澄清；沉寂库边缘激活的“痒感探测” |
| **饿** | 对“圆满”的渴望，对满足感的记忆 | 生长调度器（前额叶） | SatiationMemory 记录历史满足感；配额申请基于满足感而非仅误差 |

## 四、数据流

用户输入 → **丘脑**（文本→符号标签+接地置信度）→ **前额叶**（决策表匹配、调用小脑/海马体/杏仁核）→ 融合生成符号决策包 → **布罗卡区**（语义规划→SLM生成→护栏约束）→ 自然语言回复。

每轮对话结束后，事件存入**海马体**，工作记忆更新；后台**生长调度器**处理生长请求，**衰减机制**更新知识权重。

## 五、技术栈

| 层面 | 选型 |
|:---|:---|
| 核心引擎 | Rust（符号推理、知识存储、生长调度、记忆管理） |
| AI 接口层 | Python + PyTorch + HuggingFace Transformers |
| 绑定方案 | PyO3 + Maturin |
| 知识图谱 | 内存存储（可扩展为 SQLite / LanceDB） |
| 情景记忆 | SQLite + 网状库存点 |
| 语言模型 | 轻量 SLM（预留接口，v1.0 使用模板） |
