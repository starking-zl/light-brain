# 光脑方案实施路线图

> **版本**：v1.0  
> **更新日期**：2026年4月

## 版本规划总览

光脑方案的开发分为三个大版本，每个版本聚焦一个明确的阶段性目标，逐步从单机实验系统演进为分布式多模态智能平台。

| 版本 | 代号 | 核心目标 | 部署形态 |
|:---|:---|:---|:---|
| **v1.0** | 骨骼与血肉 | 完成完整架构，提供可实验的单机版光脑产品 | 单机部署 |
| **v2.0** | 呼吸 | 基于实验数据优化参数，实现边缘设备轻量化部署 | 边缘部署 |
| **v3.0** | 大海 | 支持公库接入、分布式集群、多模态与社会性交互 | 集群部署 |

## v2.0 规划（呼吸）

### 核心目标
基于 v1.0 积累的实验数据，对系统参数进行系统性优化，并将光脑方案裁剪适配至边缘设备（手机、树莓派、嵌入式开发板），实现低资源消耗下的流畅运行。

### 主要工作

| 工作项 | 说明 |
|:---|:---|
| **参数实验与优化** | 执行四阶段实验（合成数据→单维生长曲线→协同验证→长期稳定性），固化衰减系数、生长触发阈值、图扩散深度等关键参数 |
| **模型轻量化** | 丘脑编码器更换为 MobileBERT 或蒸馏微型 Transformer（<50MB）；布罗卡区 SLM 更换为 0.1B 级并进行 INT8 量化 |
| **存储压缩** | 知识图谱与情景记忆采用紧凑二进制格式，定期空间回收 |
| **功耗管理** | 生长、梦境等后台任务仅在设备充电且息屏时执行 |
| **边缘部署方案** | 提供 Android/iOS 封装指引（交叉编译）；提供树莓派等单板计算机预编译镜像 |

### 交付物
- 《光脑方案 v2.0 参数优化实验报告》
- 边缘端 SDK 及示例 App
- 树莓派镜像文件
- 轻量化模型权重文件

### v2.0 验收标准
- [ ] 在树莓派 4B（4GB RAM）上平均响应时间 < 2 秒
- [ ] 模型总大小 < 200MB（含丘脑+布罗卡区）
- [ ] 连续运行 24 小时内存占用稳定，无泄漏
- [ ] 四阶段实验报告完整，参数已固化进配置文件

## v3.0 规划（大海）

### 核心目标
将光脑从单机系统扩展为可集群部署的分布式智能平台，支持接入公共知识库、处理多模态输入输出，并实现多个光脑实例间的社会性交互。

### 主要功能

| 功能模块 | 说明 |
|:---|:---|
| **公库接入** | 离线导入 Wikidata/DBpedia 等公开知识图谱；MCP 协议动态查询 |
| **gRPC 分布式部署** | 六模块微服务化，支持水平扩展；知识存储分片 |
| **多模态输入** | 丘脑支持图像（CLIP/ViT）、音频（Whisper）输入 |
| **多模态输出** | 新增视觉生成模块（文本→图像/视频）和音频生成模块（文本→语音/音乐），具体模型留空待选 |
| **社会性交互** | 多光脑实例知识交换协议；辩论模式、协作模式 |
| **集群部署** | Kubernetes Helm Chart、Docker Compose 配置；Prometheus + Grafana 监控 |

### 交付物
- 支持分布式部署的完整代码
- 公库接入适配器
- 多模态示例程序（图像理解+生成、语音对话）
- 集群部署文档与监控配置

### v3.0 验收标准
- [ ] 公库接入可回答超出本地知识库范围的问题
- [ ] 三个光脑实例成功完成一次辩论协作任务
- [ ] 图像输入→文本描述→视觉生成输出链路通畅
- [ ] 音频输入→文本交互→音频生成输出链路通畅
- [ ] Kubernetes 集群中所有模块健康运行，动态扩缩容正常
- [ ] 监控仪表盘展示各模块生长配额、否决次数、生命之河指标

## 当前版本使用指引

1. **环境准备**：安装 Rust、Python 3.10+、PyTorch
2. **一键部署**：运行 `scripts/deploy_single.sh`（Linux/macOS）或 `deploy_single.ps1`（Windows）
3. **启动交互**：`python scripts/run.py`
4. **查看文档**：阅读 `docs/zh/完整架构说明.md` 了解设计细节
