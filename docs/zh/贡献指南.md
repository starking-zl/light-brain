# 贡献指南

> **版本**：v1.0  
> **更新日期**：2026年4月

感谢您对光脑方案的关注！我们欢迎任何形式的贡献，包括但不限于代码提交、文档改进、问题报告和功能建议。光脑方案的核心原则是“和平与爱”，我们期望社区互动同样遵循这一精神。

## 行为准则

请保持友善、尊重和专业的交流氛围。任何形式的骚扰、侮辱或歧视行为均不被容忍。我们致力于为所有人创造一个开放、包容的协作环境。

## 如何贡献

### 报告问题

如果您发现了 bug 或有功能建议，请在 GitHub Issues 中提交。提交时请包含以下信息：

- 清晰的问题描述
- 复现步骤（如适用）
- 预期的行为与实际的行为
- 运行环境信息（操作系统、Rust/Python 版本等）

### 代码贡献流程

1. **Fork 项目**：点击 GitHub 仓库右上角的 Fork 按钮。
2. **克隆仓库**：
    ```
    git clone https://github.com/your-username/light-brain.git
    ```
3. **创建分支**：
    ```
    git checkout -b feature/your-feature-name
    ```
4. **进行修改**：确保代码符合现有风格，并添加必要的测试和注释。
5. **运行测试**：确保所有测试通过（Rust 与 Python 测试）。
6. **提交变更**：使用清晰的提交信息。
7. **推送分支**：
    ```
    git push origin feature/your-feature-name
    ```
8. **创建 Pull Request**：在 GitHub 上发起 PR，描述修改内容和动机。

### 代码风格

- **Rust**：遵循标准 Rust 风格（使用 `cargo fmt` 格式化），并通过 `cargo clippy` 检查。
- **Python**：遵循 PEP 8 规范（使用 `black` 格式化）。
- **注释**：所有公开 API 和关键逻辑必须包含**中英双语注释**，中文在上，英文在下。

示例：
```

/// 计算衰减后的权重
/// Calculate decayed weight
pub fn calculate_decayed_weight(...) -> f32 { ... }

```

### 文档贡献

文档位于 `docs/zh/` 和 `docs/en/` 目录下。修改或新增文档时，请确保中英文版本同步更新。文档使用 Markdown 格式编写，保持结构清晰、语言准确。

### 测试

- Rust 单元测试：
    ```
    cd rust-core && cargo test --all
    ```
- Rust 集成测试：
    ```
    cargo test --test '*'
    ```
- Python 测试：
    ```
    pytest tests/
    ```

### 提交信息规范

推荐使用以下前缀遵循 Conventional Commits：

| 前缀 | 说明 |
|:---|:---|
| `feat` | 新功能 |
| `fix` | 错误修复 |
| `docs` | 文档更新 |
| `style` | 代码格式调整（不影响逻辑） |
| `refactor` | 重构 |
| `test` | 测试相关 |
| `chore` | 构建或辅助工具变动 |

示例：`feat(prefrontal): add dynamic priority to decision table`

## 开发环境设置

1. 安装 Rust（https://rustup.rs/）和 Python 3.10+。
2. 克隆仓库并进入项目目录。
3. 编译 Rust 核心：
    ```
    cd rust-core && cargo build
    ```
4. 构建 Python 绑定：
    ```
    cd python-binding && maturin develop
    ```
5. 安装 Python 依赖：
    ```
    pip install -r requirements.txt
    ```
