# 种子知识库说明

> **版本**：v1.0  
> **更新日期**：2026年4月

## 一、种子知识库的定位

光脑方案的核心主张是“生长而非训练”。种子知识库不是预置的“常识库”，而是光脑的**最小自我说明书**。它仅包含光脑自身的元知识——关于“我是谁”、“我的原则是什么”、“我如何工作”的陈述。任何可由公库检索或用户教学获得的通用常识、逻辑规则、数学公理，一律不预置。

这一设计确保：
- 光脑以“空”的状态启动，为交互式生长留出纯净土壤。
- 用户首次对话即能感知光脑的学习特性，而非面对一个“全知”系统。
- 三层记忆系统的衰减机制不被大量预置知识挤占。

## 二、种子知识库内容

种子知识库位于 `data/knowledge/seed.json`，采用逻辑条目与语言变体分离的结构。每条逻辑知识包含中文（`zh`）和英文（`en`）两个版本，初始化脚本将其展开为独立的 `KnowledgeEntry` 记录写入小脑。

### 当前种子条目

| 逻辑ID | 中文内容 | 英文内容 | 确定性 | 核心标记 |
|:---|:---|:---|:---|:---|
| `light_brain_definition` | 光脑的定义 | Light-Brain definition | 1.0 | core |
| `light_brain_principle` | 核心原则：和平与爱 | Core principle: Peace and Love | 1.0 | core |
| `light_brain_version` | 当前版本：v1.0 | Current version: v1.0 | 1.0 | 非core |
| `light_brain_capability` | 当前能力说明 | Current capability description | 1.0 | 非core |
| `light_brain_memory` | 记忆特点（会学习也会遗忘） | Memory feature (learns and forgets) | 1.0 | 非core |

### 字段说明

| 字段 | 说明 |
|:---|:---|
| `logical_id` | 逻辑知识唯一标识，用于关联多语言版本 |
| `zh` / `en` | 语言变体，包含 `subject`（主体）、`attribute`（属性）、`value`（值）、`description`（描述） |
| `certainty` | 确定性评分（0.0~1.0），种子知识均为 1.0 |
| `core` | 是否为核心知识。`true` 表示永不衰减、永不降级、受否决机制保护 |
| `tags` | 标签列表，初始化时自动追加 `lang:zh` 或 `lang:en` |

## 三、核心知识的特殊保护

标记为 `core: true` 的知识享有以下特权：
- **永不衰减**：衰减公式对其无效，权重始终为 1.0。
- **永不降级**：不会被移入沉寂库或垃圾库。
- **否决保护**：任何与之冲突的新知识将被知识错误否决拦截。

光脑的“定义”和“核心原则”标记为 `core: true`，这是系统本性的锚点。版本、能力、记忆特点虽确定性为 1.0，但未来可能变化，故不标记为 core，允许版本更新时覆盖。

## 四、初始化脚本

运行 `scripts/init_knowledge.py` 将种子知识库导入小脑。脚本逻辑：

1. 读取 `data/knowledge/seed.json`。
2. 遍历每条逻辑知识：
   - 若存在 `zh` 变体，构造中文 `KnowledgeEntry`，添加标签 `lang:zh`，调用小脑写入。
   - 若存在 `en` 变体，构造英文 `KnowledgeEntry`，添加标签 `lang:en`，调用小脑写入。
3. 输出导入结果统计。

### 使用方式
```

cd light-brain
python scripts/init_knowledge.py

```


单机部署脚本 `deploy_single.sh` 会自动执行此步骤。

## 五、扩展种子知识库

如需添加新的种子知识，请严格遵循以下原则：

**允许添加的内容**：
- 光脑自身的元知识（如新增的能力说明、交互指引）。
- 与“和平与爱”原则一致的价值观陈述。

**禁止添加的内容**：
- 任何通用常识（如地球半径、历史事件）。
- 任何逻辑规则或数学公理。
- 任何可由用户教学或公库检索获得的知识。

### 添加步骤

1. 在 `seed.json` 中添加新的逻辑条目，分配唯一的 `logical_id`。
2. 提供 `zh` 和 `en` 变体（至少提供一种）。
3. 根据内容决定 `core` 标记：仅当该知识是系统不可动摇的本性时才设为 `true`。
4. 运行 `python scripts/init_knowledge.py` 重新导入。

## 六、与公库接入的关系

种子知识库的极简设计为 v3.0 的公库接入预留了清晰边界：
- 种子仅负责“自我认知”。
- 公库负责“世界知识”。
- 用户教学负责“个人化知识”。

三者分工明确，互不重叠。光脑的生长，正是从这份最小的“自我”开始，在与世界和用户的交互中逐渐丰满。
