# 模型下载指引

> **版本**：v1.0  
> **更新日期**：2026年4月

## 一、v1.0 默认行为

光脑方案 v1.0 的核心目标是验证完整架构的可行性与自洽性。为了降低部署门槛、加快启动速度，v1.0 默认采用以下简化实现：

| 模块 | 默认实现 | 说明 |
|:---|:---|:---|
| **丘脑编码器** | 确定性伪向量（基于文本哈希） | 无需下载模型，即时可用；输出向量用于原型匹配和接地计算 |
| **布罗卡区 SLM** | 模板生成 | 根据意图和事实填充预设回复模板，无需模型推理 |

这意味着您**无需下载任何神经网络模型即可完整运行光脑 v1.0**，进行端到端对话、测试生长机制和否决机制。

## 二、启用真实神经网络

如果您希望体验真实神经网络带来的语义理解与生成能力，可以按以下指引替换默认实现。

### 2.1 丘脑编码器

**推荐模型**：`paraphrase-multilingual-MiniLM-L12-v2`（sentence-transformers）

- **参数量**：约 118M
- **向量维度**：384（需同步修改 `config/thalamus_prototypes.json` 中的向量维度及 `ThalamusConfig.vector_dim`）
- **语言支持**：中英文及多语言

**替换步骤**：

1. 安装依赖：
    ```
    pip install sentence-transformers
    ```

2. 修改 `python-ai/light_brain/thalamus_encoder/encoder.py`：

    ```python
    from sentence_transformers import SentenceTransformer

    class ThalamusEncoder:
        def __init__(self, model_name: str = "paraphrase-multilingual-MiniLM-L12-v2", vector_dim: int = 384):
            self.model = SentenceTransformer(model_name)
            self.vector_dim = vector_dim
            # ...

        def encode(self, text: str) -> np.ndarray:
            return self.model.encode(text, normalize_embeddings=True)
    ```

3. 更新 `ThalamusConfig` 中的 `vector_dim` 为 `384`（可通过配置文件或代码调整）。

**其他可选模型**：

| 模型 | 参数量 | 维度 | 特点 |
|:---|:---|:---|:---|
| `all-MiniLM-L6-v2` | 约 22M | 384 | 轻量，英文为主 |
| `bert-base-uncased` | 约 110M | 768 | 经典英文 BERT |
| `bert-base-chinese` | 约 110M | 768 | 中文 BERT |

### 2.2 布罗卡区 SLM

**推荐模型**：`Qwen/Qwen2.5-0.5B-Instruct`

- **参数量**：约 0.5B
- **特点**：中英双语，指令微调，适合生成任务
- **最低显存**：约 2GB（FP16）

**替换步骤**：

1. 安装依赖：
    ```
    pip install transformers torch
    ```

2. 修改 `python-ai/light_brain/broca_slm/generator.py`：

    ```python
    from transformers import AutoModelForCausalLM, AutoTokenizer

    class BrocaSLM:
        def __init__(self, model_name: str = "Qwen/Qwen2.5-0.5B-Instruct"):
            self.tokenizer = AutoTokenizer.from_pretrained(model_name)
            self.model = AutoModelForCausalLM.from_pretrained(
                model_name,
                torch_dtype="auto",
                device_map="auto"
            )
            # ...

        def generate(self, prompt: str, max_length: int = 128, temperature: float = 0.8) -> str:
            inputs = self.tokenizer(prompt, return_tensors="pt").to(self.model.device)
            outputs = self.model.generate(
                **inputs,
                max_new_tokens=max_length,
                temperature=temperature,
                do_sample=True
            )
            return self.tokenizer.decode(outputs[0], skip_special_tokens=True)
    ```

**其他可选模型**：

| 模型 | 参数量 | 特点 |
|:---|:---|:---|
| `microsoft/phi-2` | 约 2.7B | 推理能力强，英文为主 |
| `TinyLlama/TinyLlama-1.1B-Chat-v1.0` | 约 1.1B | 轻量对话模型 |
| `google/gemma-2b-it` | 约 2B | 谷歌轻量指令模型 |

## 三、模型文件存放位置

下载的模型权重将默认缓存于以下目录（由 HuggingFace Transformers 管理）：

- Linux/macOS: `~/.cache/huggingface/hub/`
- Windows: `%USERPROFILE%\.cache\huggingface\hub\`

如需指定自定义存放路径，可在加载模型时设置 `cache_dir` 参数。

光脑方案的数据目录 `data/models/` 预留了以下子目录，供存放自行下载或微调后的模型：

- `data/models/thalamus_encoder/`
- `data/models/broca_slm/`

## 四、边缘设备轻量化建议（v2.0 预览）

v2.0 将提供正式的边缘部署方案，以下为预览建议：

| 策略 | 说明 |
|:---|:---|
| **模型量化** | 使用 INT8 或 INT4 量化，将 0.5B 模型压缩至 500MB 以下 |
| **模型蒸馏** | 使用更小的蒸馏模型（如 `Qwen2.5-0.1B`） |
| **本地缓存** | 首次下载后离线使用，无需网络 |

## 五、辅助脚本

项目提供了 `scripts/download_models.py` 脚本，用于检查模型下载状态并输出指引。运行方式：
```

python scripts/download_models.py

```


该脚本不会自动下载模型，而是根据当前配置给出具体的下载和替换步骤说明。

## 六、常见问题

**Q：为什么 v1.0 不直接集成真实模型？**

A：光脑方案的核心价值在于架构本身——生长机制、三层记忆、否决系统、生命之河。使用简化编码器和生成器可以：
- 降低部署门槛，无需 GPU 即可运行。
- 确保行为确定性，便于调试和测试。
- 将“接入真实模型”作为一个清晰的演进步骤，符合“从骨骼到血肉”的版本哲学。

**Q：替换真实模型后，是否需要重新训练原型向量？**

A：是的。原型向量需要与新编码器的语义空间对齐。您可以通过以下方式之一完成：
- 使用新编码器对少量标注样本编码，重新初始化原型向量。
- 保持现有原型，通过交互式校准逐步调整（`calibrate` 方法）。

**Q：能否混合使用——丘脑用真实模型，布罗卡区用模板？**

A：完全可以。各模块独立，您可以根据需要逐步替换。
